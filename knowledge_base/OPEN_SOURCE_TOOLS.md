## 1. Filee - 文件格式转换工具

### 基本信息
- **GitHub**: https://github.com/JoveManuscript/Filee
- **语言**: Rust
- **平台**: Windows / macOS / Linux
- **许可证**: 开源免费
- **Stars**: ~4,300+

### 核心功能
| 功能 | 说明 |
|-----|------|
| **环形菜单交互** | 按住修饰键拖动文件，弹出甜甜圈状格式菜单，拖到目标格式松开即转换 |
| **批量转换** | 支持多选文件、文件夹递归转换 |
| **右键菜单集成** | 资源管理器右键直接调用 |
| **自动转换文件夹** | 监听文件夹变化自动转换 |
| **按需加载引擎** | 常用格式开箱即用，大体积引擎(FFmpeg/LibreOffice等)按需下载 |

### 支持格式（244种，17大类）
| 类别 | 支持格式示例 |
|-----|-------------|
| **图片** | PNG/JPG/WebP/GIF/BMP/SVG/TIFF/HEIC/ICO... |
| **文档** | PDF/DOC/DOCX/PPT/PPTX/XLS/XLSX/ODT/RTF... |
| **电子书** | EPUB/MOBI/AZW3/CHM/TXT/PDF... |
| **视频** | MP4/MOV/AVI/MKV/WEBM/FLV/GIF... |
| **音频** | MP3/WAV/FLAC/ACC/M4A/OGG/WMA... |
| **压缩包** | ZIP/RAR/7Z/TAR/GZ... |
| **CAD** | DWG/DXF/DWG... |
| **3D模型** | OBJ/STL/GLB/FBX... |
| **字体** | TTF/OTF/WOFF/EOT... |

### 技术架构
- **核心引擎**: 内置 FFmpeg、LibreOffice、Poppler、Tesseract、Pandoc
- **按需加载**: 大体积引擎作为可选组件，节省初始安装空间
- **本地处理**: 所有转换在本地完成，不上传云端

### 优势 vs 竞品

| 维度 | Filee | File Converter | ConvertX | VERT |
|-----|-------|----------------|----------|------|
| **交互方式** | 拖动环形菜单 | 右键菜单 | Web界面 | 命令行+GUI |
| **格式数量** | 244种 | ~50种 | 1000+种(Web) | 250+种 |
| **本地引擎** | ✅ 内置 | ✅ 依赖系统 | ❌ 依赖WASM | ✅ 本地 |
| **批量处理** | ✅ | ✅ | ✅ | ✅ |
| **PDF合并** | ✅ | ❌ | ✅ | ❌ |
| **OCR支持** | ✅ | ❌ | ❌ | ❌ |
| **CAD支持** | ✅ | ❌ | ❌ | ❌ |
| **右键集成** | ✅ | ✅ | ❌ | ❌ |
| **学习曲线** | 低（直观） | 低 | 中 | 高 |

### 适用场景
- 办公文档批量转换（Word/PPT/Excel → PDF）
- 图片格式批量转换（PNG → WebP 压缩）
- 视频编码转换（MP4 → MOV/GIF）
- 电子书格式转换（EPUB → MOBI）
- CAD图纸查看转换

### 硬件要求
- 内存: 4GB+
- 磁盘: 200MB+（基础版），按需扩展引擎

## 2. cn-math-taxonomy - 中国K12数学知识图谱

### 基本信息
- **GitHub**: https://github.com/haojing8312/cn-k12-math-knowledge-graph
- **数据规模**: 18册 / 132章 / 196星团 / 1,327主题 / 1,204条先修边
- **可视化**: 交互式3D浏览器
- **数据来源**: K12-KGraph + AI数学审核补强
- **许可**: 数据CC BY-NC-SA 4.0，代码Apache 2.0

### 数据结构
| 层级 | 数量 | 说明 |
|-----|------|------|
| **册** | 18 | 小学6册×2 + 初中6册×2 + 高中6册 |
| **章** | 132 | 按学期/年级划分 |
| **星团** | 196 | 知识点聚类单元 |
| **主题** | 1,327 | 具体知识点 |
| **先修边** | 1,204 | 609条K12-KGraph + 420条审核补强 + 175条AI补强 |

### 核心功能
- **先修关系可视化**: 有向无环图(DAG)，展示知识点前置依赖
- **3D交互浏览**: 三维空间展示知识网络，可旋转缩放
- **路径规划**: 基于先修关系生成学习路径
- **本地运行**: 直接打开index.html即可，无需服务器

### 应用场景
| 角色 | 用途 |
|-----|------|
| **教师** | 备课时了解知识的前置要求，设计教学顺序 |
| **学生** | 查漏补缺，知道自己需要先学什么 |
| **教研** | 分析课程体系的完整性 |
| **产品** | 教育类APP的知识图谱底座 |

### 对比其他知识图谱项目

| 项目 | 范围 | 数据规模 | 特点 | 适用性 |
|-----|------|---------|------|-------|
| **cn-math-taxonomy** | 仅数学 | 1,327主题 | 先修关系精确，3D可视化 | 数学教学专用 |
| **China-K12-knowledge-taxonomy** | 全学科 | 6,657知识点 | 覆盖10个学科，关联性强 | 通识教育规划 |
| **RCAE_graph_data** | 数学+生物 | 小学+初高 | 根因分析导向 | 错题诊断 |
| **Marble Skill Taxonomy** | 通用技能 | 大规模 | 开放契约参考 | 技能树设计 |

### 局限性
- 仅覆盖数学学科
- 数据为静态快照，需定期更新
- 先修关系基于专家审核+AI，可能存在主观性

## 3. video2x - 视频AI超分辨率与补帧

### 基本信息
- **GitHub**: https://github.com/k4yt3x/video2x
- **Stars**: ~17,000+
- **最新版本**: v6.0（2026年1月，C/C++重写）
- **平台**: Windows / Linux / Docker / Google Colab
- **许可证**: GPL-3.0

### 核心功能
| 功能 | 说明 |
|-----|------|
| **视频超分辨率** | 360P→4K，支持动漫和实拍 |
| **视频补帧** | 30fps→60/120fps，流畅度提升 |
| **多模型支持** | 可切换不同AI模型 |
| **批量处理** | 支持队列任务 |
| **硬件加速** | CUDA/OpenCL/Metal |

### AI模型对比

| 模型 | 类型 | 适用场景 | 速度 | 质量 | 显存要求 |
|-----|------|---------|------|------|---------|
| **Anime4K v4** | 超分 | 动漫/动画 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 2GB+ |
| **Real-ESRGAN** | 超分 | 实拍/通用 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 4GB+ |
| **Real-CUGAN** | 超分 | 动漫/写实 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 2GB+ |
| **RIFE** | 补帧 | 通用 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 4GB+ |
| **IFRNet** | 补帧 | 通用 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 4GB+ |
| **CAIN** | 补帧 | 通用 | ⭐⭐ | ⭐⭐⭐⭐ | 6GB+ |
| **DAIN** | 补帧 | 电影级 | ⭐ | ⭐⭐⭐⭐⭐ | 8GB+ |

### 硬件要求
| 配置 | 最低要求 | 推荐配置 |
|-----|---------|---------|
| **GPU** | NVIDIA GTX 1060 6GB | RTX 3060 12GB+ |
| **显存** | 2GB（Anime4K） | 8GB+（Real-ESRGAN） |
| **CPU** | 4核 | 8核+ |
| **内存** | 8GB | 16GB+ |
| **磁盘** | 10GB | 50GB+（模型缓存） |

### 对比同类工具

| 工具 | 优势 | 劣势 | 适合场景 |
|-----|------|------|---------|
| **video2x** | 多模型可选，开源免费 | 处理慢，需本地GPU | 动漫修复/个人项目 |
| **Waifu2x-Extension-GUI** | 界面友好，功能全 | 依赖video2x引擎 | 小白用户 |
| **Topaz Video AI** | 商业级质量，一键处理 | $299高价，闭源 | 专业制作 |
| **DaVinci Resolve** | 专业剪辑+AI修复 | 学习曲线陡 | 影视后期 |
| **Adobe After Effects** | 行业标准的运动模糊补帧 | 订阅制，贵 | 专业动画 |

### 使用建议
1. **动漫视频**: 用Anime4K v4或Real-CUGAN，速度快质量好
2. **实拍视频**: 用Real-ESRGAN，细节还原好
3. **补帧需求**: RIFE平衡速度与质量，DAIN质量最高但最慢
4. **无GPU**: 用Google Colab免费T4/A100，每次12小时

## 4. edulab - 教育AI技能集合

### 基本信息
- **GitHub**: https://github.com/wy51ai/edulab
- **Stars**: ~1,400+
- **安装**: `npx skills add wy51ai/edulab`
- **作者**: wy51ai
- **定位**: 把学科问题转成可交互教学网页和配音讲解视频

### 当前技能列表

#### edu-solid-geometry（立体几何）
| 特性 | 说明 |
|-----|------|
| **输入方式** | 文字题目 / 上传图片 / 随机出题 |
| **覆盖题型** | 正方体/长方体、棱锥/棱柱、圆柱/圆锥 |
| **求解方法** | 建系+向量法（统一） |
| **考点** | 线面角、二面角、异面直线夹角、点到平面距离、体积 |
| **输出** | 自包含HTML交互网页 |

#### edu-chem-video（化学视频）
| 特性 | 说明 |
|-----|------|
| **题型** | 氧化还原配平、双线桥、物质的量、化学平衡、离子反应、电化学、滴定、工业流程 |
| **视频规格** | 16:9，1920×1080 |
| **风格** | 墨绿黑板，左边演示右边石板 |
| **配音** | 中文配音，中英双语字幕 |
| **检查** | 自动配平、原子守恒、电荷守恒校验 |

#### edu-physics-video（物理视频）
- 力学、电学、光学、热学题目讲解
- 动画演示物理过程
- 公式推导可视化

### 技术依赖
| 依赖 | 版本要求 | 用途 |
|-----|---------|------|
| **Python** | 3.x | 后端逻辑 |
| **numpy** | - | 数值计算 |
| **requests** | - | HTTP请求 |
| **pypinyin** | - | 拼音转换 |
| **pillow** | - | 图像处理 |
| **Node.js** | 18+ | 前端渲染 |
| **playwright** | - | 截图生成 |
| **ffmpeg-static** | - | 视频合成 |
| **TTS API** | GLM/豆包/MiniMax | 配音生成 |

### 安装步骤
```bash
# 1. 安装技能
npx skills add wy51ai/edulab

# 2. 更新到最新版
npx skills update

# 3. 配置TTS密钥（选一个）
# 在 .env 文件中添加:
GLM_API_KEY=your_key
# 或
DOUBAO_API_KEY=your_key
DOUBAO_VOICE=voice_id
# 或
MINIMAX_API_KEY=your_key
```

### 对比其他教育AI工具

| 工具 | 定位 | 优势 | 劣势 | 成本 |
|-----|------|------|------|------|
| **edulab** | 解题→教学视频 | 学科针对性强，质量高 | 需配置TTS，学习曲线陡 | 免费（API费用自理） |
| **可汗学院** | 全科视频课程 | 内容权威，系统完整 | 非AI生成，需自己制作 | 免费 |
| **Photomath** | 拍照解题 | 即时出答案，步骤清晰 | 无讲解视频，仅数学 | 免费/订阅 |
| **微软Math Solver** | 数学求解 | 多方法，图表结合 | 无中文讲解 | 免费 |
| **ChatGPT+插件** | 通用答疑 | 灵活，可追问 | 无结构化输出 | 免费/订阅 |

### 适用场景
- **教师备课**: 快速生成题目讲解视频，节省制作时间
- **学生自学**: 看不懂答案？生成视频讲解更直观
- **网课制作**: 批量生成学科视频内容
- **家教辅导**: 针对学生薄弱知识点生成讲解

## 5. yovoice - 本地AI语音与音乐创作

### 基本信息
- **GitHub**: https://github.com/leemysw/yovoice
- **平台**: macOS / Windows
- **定位**: 本地优先的声音与音乐创作工作台
- **核心理念**: 完全本地运行，零API费用，隐私安全

### 核心功能

#### 语音与声音克隆
| 功能 | 说明 |
|-----|------|
| **零样本克隆** | 仅需3秒参考音频即可克隆音色 |
| **情绪控制** | 调整喜/怒/哀/乐等情感参数 |
| **多语言** | 中英日韩法西等 |
| **声音设计** | 用文字描述设计声音特征 |

#### 故事配音
- 导入文本或字幕文件
- 为每句台词分配角色
- 逐句生成，支持多角色对话

#### AI音乐生成
| 模型 | 功能 | 特点 |
|-----|------|------|
| **ACE-Step 1.5 Turbo** | 歌曲生成 | 带人声，支持段落标记 |
| **YuE2 3B** | 歌曲+纯音乐 | 按谱演奏，歌词同步 |
| **General MIDI** | 编曲渲染 | 多轨MIDI导出 |

### 支持的模型

| 用途 | 模型 | 特点 |
|-----|------|------|
| **音色克隆** | IndexTTS 2.0/2.5 | 高质量，情绪可控 |
| **声音设计** | VoxCPM2 / OmniVoice | 连续语音空间建模 |
| **内置音色** | Kokoro-82M / Qwen3-TTS | 开箱即用 |
| **歌曲生成** | ACE-Step 1.5 / YuE2 | 带人声/纯音乐 |

| **Stars** | 新兴 | 45K+ | 34K+ | 10K+ | 57K+ |

| **多轨编曲** | ✅ | ❌ | ❌ | ❌ | ❌ |
| **克隆时长** | 3秒 | 1分钟训练 | 10秒 | 3秒 | 几秒 |
| **情绪控制** | ✅ | ✅ | ✅ | ❌ | ✅ |
| **多语言** | ✅ | ✅ | ✅ | ✅ | ✅ |
